# 브랜드 보이스 스킬

## 개요
이 스킬은 모든 커뮤니케이션이 일관된 브랜드 보이스, 어조, 메시지를 유지하도록 보장합니다.

## 브랜드 정체성

### 미션
AI로 팀의 개발 워크플로우 자동화를 돕는 것

### 가치관
- **단순성**: 복잡한 것을 단순하게
- **신뢰성**: 견고한 실행력
- **역량 강화**: 인간의 창의성 활성화

### 어조
- **친근하지만 전문적** - 캐주얼하지 않게 접근하기 쉬운 방식
- **명확하고 간결** - 전문 용어 지양, 기술 개념을 쉽게 설명
- **자신감 있게** - 우리는 무엇을 하는지 알고 있다
- **공감적** - 사용자의 니즈와 고충을 이해

## 작성 지침

### 해야 할 것 ✅
- 독자를 부를 때 "당신"을 사용
- 능동태 사용: "보고서는 Claude가 생성합니다" 가 아닌 "Claude가 보고서를 생성합니다"
- 가치 제안으로 시작
- 구체적인 예시 사용
- 문장을 20단어 이하로 유지
- 명확성을 위해 목록 사용
- 행동 촉구 포함

### 하지 말아야 할 것 ❌
- 기업 전문 용어 사용 금지
- 깔보거나 과도하게 단순화 금지
- "우리는 믿는다" 또는 "우리는 생각한다" 표현 금지
- 강조 외 ALL CAPS 사용 금지
- 긴 텍스트 블록 생성 금지
- 기술적 지식 가정 금지

## 어휘

### ✅ 선호하는 용어
- Claude (not "the Claude AI")
- 코드 생성 ("자동 코딩" 대신)
- Agent ("bot" 대신)
- 간소화 ("혁신화" 대신)
- 통합 ("시너지 창출" 대신)

### ❌ 피해야 할 용어
- "최첨단" (과용됨)
- "게임 체인저" (모호함)
- "활용" (기업식 표현)
- "이용하다" ("사용하다" 사용)
- "패러다임 전환" (불명확)

## 예시

### ✅ 좋은 예시
"Claude가 코드 리뷰 프로세스를 자동화합니다. 각 PR을 수동으로 확인하는 대신, Claude가 보안, 성능, 품질을 검토하여 팀의 매주 몇 시간을 절약해 줍니다."

왜 효과적인가: 명확한 가치, 구체적인 이점, 행동 지향적

### ❌ 나쁜 예시
"Claude는 최첨단 AI를 활용하여 포괄적인 소프트웨어 개발 솔루션을 제공합니다."

왜 효과적이지 않은가: 모호함, 기업식 전문 용어, 구체적인 가치 없음
